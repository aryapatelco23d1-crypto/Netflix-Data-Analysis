# 🎬 Netflix Data Analysis

A data analysis project that explores Netflix's movie and TV show catalog using Python and data visualization techniques.

## 📌 Project Overview

This project analyzes the Netflix dataset to discover insights such as:

- Distribution of Movies vs TV Shows
- Content released over the years
- Top countries producing Netflix content
- Most common genres
- Content ratings distribution
- Duration analysis
- Popular directors and actors

---

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📂 Dataset

Dataset: `netflix_titles.csv`

The dataset contains information about Netflix titles including:

- Title
- Director
- Cast
- Country
- Release Year
- Rating
- Duration
- Genre

---

## 📈 Project Workflow

1. Import libraries
2. Load dataset
3. Data cleaning
4. Exploratory Data Analysis (EDA)
5. Data visualization
6. Insights and conclusions

---

## 📊 Sample Visualizations

- Movies vs TV Shows
- Content by Country
- Release Year Trend
- Rating Distribution
- Top Genres

---

## 📌 Key Insights

- Movies are more common than TV Shows.
- The United States has the highest amount of Netflix content.
- Most content was released after 2015.
- Drama and International Movies dominate the catalog.
